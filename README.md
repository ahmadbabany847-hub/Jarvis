# JARVIS AI

Cloudflare Workers + Workers AI web app.

## Structure

- `public/index.html`
- `public/app.js`
- `src/index.js`
- `package.json`
- `wrangler.jsonc`

## Cloudflare deploy

Build command: leave empty

Deploy command:
`npm run deploy`

Root directory:
`/`

Workers AI binding is declared in `wrangler.jsonc` as `AI`.
